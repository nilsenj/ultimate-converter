# Ultimate Converter 0.1.0 Beta 3 — recovery and guarded acceleration

Windows 10/11 x64. Built in Flutter Release mode (0.1.0+3). Every conversion feature remains free and offline.

## New

- Recover interrupted media sessions: restore the selected file and settings, recover validated unsaved results, and reconcile files saved before an interruption. Interrupted encoding restarts from zero; it does not resume at the last frame. Explicitly discarded work is not recovered.
- Lower default CPU thread budgets, resource admission checks, and low-memory cancellation help leave room for desktop work.
- Experimental NVIDIA MP4 encoding: H.264 SDR and HEVC Main10 HDR, including resolution and size controls. HDR-to-SDR and supported Dolby Vision profile-8/HDR10-base conversion retain explicit dynamic-metadata-loss consent.
- Close/Escape confirmation protects active or unsaved work; outside clicks no longer discard it. Fractional progress and processed video time make long jobs clearer.

## Important acceleration limitation

GPU availability is deliberately bound to an accepted exact device/driver/engine receipt and a live encoder check. This build includes acceptance only for the developer's RTX 4060 Laptop GPU installation with driver 32.0.16.1742. Merely owning the same GPU model does not enable it. Other computers retain available CPU routes; HEVC Main10 GPU-only routes remain hidden. Intel acceleration and hardware WebM encoding are not available. This is not a general NVIDIA acceleration release.

## Existing features

Still images; TXT/Markdown/HTML/RTF/DOCX/ODT/PDF; LOG and structured JSON/XML; selected camera RAW variants; audio/video; supported 4K/HDR and shrinking; Windows media inputs up to 50 GB; storage checks, Cancel, validated Save, Open links and last-20 saved-file history. Capabilities depend on the input and installed engines. Archive conversion is not shipped.

## Validation and limits

107 Flutter tests and clean analysis; 71 production document/text conversions; 48 short native GPU HDR/SDR conversions, three SDR presets, CPU budget checks and packaged separate-process recovery checks. The shipped installer/ZIP have checksums and include runtime libraries, notices and corresponding third-party sources.

Unsigned public beta. Full-movie stress/thermal tests, independent HDR display fidelity, wider GPU/driver coverage, clean-machine testing and physical power-loss durability remain unverified. Resource budgets are estimates, not a hard memory cap. Recovery currently covers media sessions. PDF export reconstructs supported content; no OCR. Some audio codecs, RAW variants and Dolby Vision profiles are unsupported. Shrinking is not guaranteed; impossible targets fail safely.
