# Ultimate Converter 0.1.0 Beta 6

Windows 10/11 x64. App build 0.1.0+15. All conversion features remain free and offline.

## Changes since Beta 5

- Redesigned interface: aurora background, floating glass header, larger drop card with format-family chips, gradient primary actions, card-style recent conversions and a refreshed conversion popup.
- Layout fidelity: supported alignment, indents, spacing, line height, shading, borders and table layout are kept between HTML, DOCX, ODT, RTF and PDF.
- Keep styles switch: document conversions remain a plain structured copy by default. Turn on **Keep styles and layout** to retain supported appearance in rich target formats.
- PDF import now recovers more embedded images, font information, table geometry and character styling from conventional PDFs.
- Exact page copy: PDF conversions to HTML, DOCX, ODT, RTF or PDF can rebuild each page with a visual backdrop and selectable positioned text. Use flowing mode for a more editable copy intended for tools such as Google Docs.
- Media, archive and RAW engines, bundled fonts and notices remain the verified Beta 5 payload. No route, format or limit was added or removed.

## Download

Use the installer for per-user installation or extract the portable ZIP into a new folder and run `ultimate_converter.exe`. Close an older instance yourself before updating. Keep the entire portable folder together. `SHA256SUMS.txt` covers both downloads.

## Limits and validation

This remains an unsigned beta, so Windows may show a publisher warning. The package includes the Microsoft Visual C++ runtime and passed dependency and per-file integrity audits. The installer passed install, launch, reinstall and uninstall checks across all 179 payload files. The production DLL passed 46 document routes on repository fixtures and six routes for an authorized PDF reproduction. Video, audio, RAW and archive conversion were not re-tested with the rebuilt native library. Clean-machine, broad-hardware and accessibility testing remain pending. See `RELEASE-VALIDATION.txt` inside the package.
