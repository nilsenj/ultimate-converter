# Ultimate Converter 0.1.0 Beta 5

Windows 10/11 x64. App build 0.1.0+14. All conversion features remain free and offline.

## Changes since Beta 4

- WebM AV1 GPU encoding, including supported 10-bit HDR and shrinking, on verified NVIDIA hardware. The processing picker shows CPU/GPU selection and disables incompatible settings. Tested on RTX 4060 Laptop; hardware availability still depends on the accepted device/driver/build, not just the model name.
- AVI output with CPU MPEG-4/MP3, resolution, quality and maximum-size controls.
- Optional damaged-audio repair for SDR video: replace short damaged sections with silence, up to five seconds total. A warning remains visible before Save. Severe damage and video corruption still fail safely; originals are untouched.
- Less repeated preparation for large videos. Fresh successful encodes use bounded output checks when completion evidence is consistent; recovery or inconclusive timing still receives deeper validation.
- Improved cancellation cleanup and recovery behavior. Interrupted encoding restarts from the beginning; verified unsaved results can be saved.
- Offline archive creation/extraction/conversion for ZIP, 7z, TAR, TAR.GZ, TAR.XZ and TAR.BZ2, with RAR extraction/conversion.
- Document engine packaging fixes, broader PDF compatibility, saved-webpage HTML import, HTML text/Markdown/typed JSON/XML exports, and bundled PDF font fallback including emoji.
- Clearer conversion dialogs, progress and errors. Saved-file history and safe Save remain available.

## Download

Use the installer for per-user installation or extract the portable ZIP into a new folder and run ultimate_converter.exe. Close an older instance yourself before updating its installation. Keep the entire portable folder together. SHA256SUMS.txt covers both downloads.

## Limits and validation

This remains an unsigned beta. Windows may show a publisher warning. Clean-machine, broad hardware and full-length large-video stress testing are pending. PDF export reconstructs content and may change complex layouts; OCR is not included. HDR playback requires compatible hardware/software. Supported Dolby Vision re-encoding uses the compatible HDR10 base layer with explicit consent to drop dynamic metadata. Audio repair changes sound and is opt-in.

Repair was verified with synthetic middle/tail corruption and a short authorized AVI excerpt, through CPU MP4 and RTX 4060 AV1 WebM Save plus complete independent decode. No full-film repair guarantee is made. See RELEASE-VALIDATION.txt inside the package.
