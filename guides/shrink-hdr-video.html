Make HDR video smaller on Windows

Use resolution, quality and size controls while keeping supported HDR information.

Pick a supported HDR route

Open the video and select Keep HDR. For compatible input and detected NVIDIA hardware, WebM AV1 (GPU) offers ten-bit HDR encoding. This route was tested on an RTX 4060 Laptop GPU; other devices depend on capability checks.

Choose how to shrink it

Select a smaller resolution such as 1080p or 720p when offered. Choose Smaller file under Quality preset, or set a Maximum size. A size target that is too small for the duration and audio may be rejected; larger targets allow more detail.

Understand the HDR tradeoff

Supported Dolby Vision conversion uses the compatible HDR10 base layer. You must explicitly consent to removing Dolby Vision/HDR10+ dynamic metadata where requested. This is not preservation of every original HDR feature.

Check playback first

AV1 WebM requires an AV1-capable player; HDR also requires a suitable display and playback path. If you need an SDR output, choose HDR to SDR and a compatible offered format instead.

Time and storage

GPU encoding can accelerate supported routes, but decoding and color processing may still use CPU. The app shows estimates and temporary-storage needs. Encoding interrupted before completion restarts from the beginning; recovery is not frame-level resume.
